# Кристал Мови — English Adventure (MVP)

2D-платформер для вивчення англійської. Один файл `index.html` (HTML + CSS + vanilla JS + Canvas),
без збірки, без npm, без сервера. Працює з локального файлу і з GitHub Pages.

**Гра повністю англомовна**: інтерфейс, меню, завдання, пояснення помилок, квести й діалоги — тільки English.
Українська мова в грі не використовується (цей README — єдиний виняток, це технічна документація).

## Запуск

1. Локально: відкрий `index.html` у браузері (Chrome, Edge, Safari, Firefox).
2. GitHub Pages: поклади `index.html` у корінь репозиторію → Settings → Pages → Deploy from branch → `/root`.

Прогрес зберігається в `localStorage` цього браузера (ключ `crystal-of-words-v1`).

## Як додавати контент

**Нове слово** → у `WORDBANK` у потрібну тему і рівень (`lv[0]` easy, `[1]` medium, `[2]` hard):

```js
animals:{n:'Animals',lv:[ ['cat|🐱','owl|🦉'], [...], ['predator||an animal that hunts other animals'] ]}
```

Формат: `"english|емодзі|коротке англійське визначення"`. Обидва останні поля необов'язкові:
емодзі дає завдання з картинкою, визначення — завдання типу *Which word means this?*.
Для складного рівня визначення бажані (вони замінюють переклад).
З одного слова гра автоматично будує до 8 форматів завдань: picture → word, word → picture,
definition → word, listening, odd one out, correct spelling, missing letters, anagram, listen & type.

**Нова Vocabulary-тема** → новий ключ у `WORDBANK`. Чекбокс у меню тем з'явиться сам.

**Нове Grammar-запитання** → у `GRAMMARBANK` у масив потрібної складності:

```js
{k:'ch', q:'He ___ football.', o:['play','plays'], a:1, ee:'We add -s after he, she and it.'}
```

Типи `k`: `ch` — вибір варіанта, `in` — ввести відповідь (кілька варіантів через `|`),
`sq` — скласти речення (`a` — правильне речення), `er` — знайти помилку (`o` — слова, `a` — індекс помилкового).
`ee` — коротке англійське пояснення, яке гравець бачить після відповіді. Українських пояснень немає.

**Новий світ** → об'єкт у `WORLDS` (англійська назва, кольори неба/землі, набір ворогів, бос, тип місії `key` або `shards`).

**Новий монстр** → запис у `FOECFG` (розмір, hp, швидкість, `fly`/`shoot`) + гілка у `drawFoe()`.

**Нове спорядження** → об'єкт у `GEAR` + обробка ефекту там, де він потрібен
(`fight()` — зброя, `ask()` — шоломи, `movePlayer()` — черевики, `update()`/`hitBlock()` — амулети).

**Бонус за серію відповідей** → `STREAK_JUMP` і `STREAK_TIME` угорі файлу, нарахування — `applyStreakJump()`
у `record()`. 1 правильна відповідь = +25% висоти стрибка на 30 с, 3 поспіль = +50%, 5 поспіль = ×2.
Слабший рівень не перебиває сильніший, лише оновлює таймер. Множник — це висота, а не швидкість
(у коді береться `Math.sqrt(jumpMult)`, бо висота стрибка пропорційна квадрату початкової швидкості).

**Суперстрибок** → константи `SUPER_CHARGES` (кількість польотів), `SUPER_TIME` (тривалість у кадрах, 120 ≈ 2 с)
і `FLY_TOP` (висота зависання). Заряди видаються в `startLevel()`, логіка польоту — в `movePlayer()`,
активація — у `superJump()`. Черевики стрибка дають +1 політ.

**Новий буст** → запис у `BOOSTS` + кнопка в масиві `bl` усередині `ask()` (або обробка в `useFieldBoost()`).

**Новий мініквест** → додай гілку в `runQuest()`: намалюй свій HTML у `#quest-card`
і виклич `finish(true/false, 'повідомлення')`.

**Рунні камені** (💠, нескінченне джерело монет) → сегмент `'stone'` у `buildLevel()`, взаємодія — `runeStone()`.
Нагорода спадає з кожною відповіддю біля того самого каменя: 6 → 5 → 4 → 3 → 2 і далі по 2, тож рівень
завжди можна дофармити, але швидко «набити» монети не вийде. На рівні 4–6 каменів, один обов'язково перед
босом і один перед фінішем. Генератор також гарантує, що загальний запас монет на рівні щонайменше в 1.7 раза
більший за потрібний мінімум.

**Новий тип сегмента рівня** → додай `case` у `switch` всередині `buildLevel()` і додай його в `pool`.

## Графіка та звук

* **Паралакс у 3 шари** — власні силуети для кожної теми світу (`silhouette()`): ліс, кристали, дюни, гори,
  хвилі й щогли, будівлі з шестернями, вежі замку, вулкан, небесні острови, шпилі темного королівства.
* **Погода** для кожного світу (`WEATHER`): листя, іскри, піщані пориви, сніг, бризки, пара, привидні
  вогники, жар вулкана, хмари, темні порошинки.
* **Головний герой — намальований спрайт** (12 кадрів, нарізаних із твого аркуша й вбудованих у файл
  у base64, тож гра лишається одним index.html): 5 кадрів бігу, стрибок, падіння, присідання після
  приземлення, атака мечем, отримання шкоди, стійка. Кадр обирається зі стану героя (`heroFrame()`),
  масштаб рахується автоматично від висоти кадру `idle` (`HERO_TARGET_H`, зараз 60 px), прив'язка — по
  ступнях. Якщо картинка чомусь не завантажиться, вмикається старий векторний герой (`drawPlayerVector`).
  Пил з-під ніг, аура бонусу стрибка, полум'я суперстрибка і смужка польоту малюються поверх спрайта.
* **Анімовані вороги**: слим стискається, кажан махає крилами, маг обертає кулю, голем гупає, привид
  хвилюється, мімік клацає кришкою, спалах при влучанні, шкала HP.
* **Бос** дихає, світить очима і **телеграфує атаку** (аура спалахує за мить до удару).
* **Ефекти**: тряска камери при ударах і появі боса, кільцевий вибух після перемоги над босом, «пуф» на місці
  монстра, пульсуючі кубики, обертові монети, вируючий портал, хвилястий прапор фінішу, віньєтка,
  червоний спалах при втраті серця, плавне затемнення на старті рівня.
* **Звук**: шаруваті SFX через WebAudio (стрибок, кроки, приземлення, монета, удар по кубику, правильна/
  неправильна відповідь, перемога над монстром, удар по босу, фанфари, поразка).
* **Процедурна музика** — окрема тема для кожного світу (`MTHEMES`: тональність, лад, гармонія, темп, тембр)
  з басом, арпеджіо, мелодією та ритмом; під час бою з босом вмикається швидша й агресивніша версія.
  У «Налаштуваннях» окремо вмикаються SFX і музика, гучність — Muted / Low / Medium / High.
* **Продуктивність**: віньєтка й ореол сонця запікаються в offscreen-canvas (`bake()`), градієнти будуються
  раз на рівень, усе поза екраном не малюється. Кадр (update + draw) — близько 3–4 мс у програмному
  растеризаторі, тобто із запасом для телефонів.

## Що вже працює

Меню → карта 10 світів → вибір тем (16 Vocabulary + 12 Grammar) → складність (Easy/Medium/Hard) →
брифінг зі спорядженням і бустами → рівень: біг, стрибки, рухомі платформи, провалля, пастки,
рунні камені з нескінченним фармом монет, 6 типів кубиків з Vocabulary-завданнями, 8 класів монстрів з Grammar-завданнями, скриня з ключем,
колодязі з 4 типами мініквестів, секретні зони, клітка чарівника, бос з 3–5 фазами та ареною-бар'єром,
фініш з перевіркою місії → результати, зірки, монети, магазин, рюкзак знань з озвучкою (Web Speech API),
адаптивне повторення помилок, досягнення, щоденні завдання, режим учителя (статистика), збереження.
Буст Translation замінено на **Dictionary** — він дає додаткову англійську підказку (визначення або тему).

## Онлайн-гра (Play Together)

Два гравці, один рівень. Сервер кімнат **уже вбудований** у гру (Supabase-проєкт `yhekszqxheljbxoucalt`),
тож учень просто відкриває сторінку, створює кімнату й диктує код — нічого налаштовувати не треба.
У сторінці лежить лише `anon public` ключ, який саме для цього й призначений і дає доступ виключно
до Realtime-каналів. Таблиць, авторизації та SQL не потрібно.

Якщо колись знадобиться інший проєкт (наприклад, окремий для школи), у Play Together → Server можна
вставити свої *Project URL* і *anon public* ключ і натиснути **Test connection**; кнопка
**Use the built-in one** повертає все назад.

* **🏁 Race** — обидва біжать один і той самий рівень, бачать одне одного напівпрозорим силуетом
  з іменем і аватаркою; у HUD видно монети й прогрес суперника; наприкінці — порівняння часу, монет
  і точності.
* **🤝 Co-op** — спільна мета: монети йдуть у спільний гаманець, ключ, уламки кристала й бос
  зараховуються обом, а **помилка одного гравця передається другому** — партнер бачить те саме питання
  й може врятувати відповідь. Помилка все одно записується в статистику того, хто помилився
  (щоб адаптивне повторення працювало), але удару по грі не буде.
* Хост створює кімнату з 4-символьним кодом і натискає Start — його світ, складність, теми, **seed**
  і навіть **власні уроки** розсилаються партнеру, тож рівень і слова в обох однакові, навіть якщо
  партнер твого курсу ніколи не бачив.
* Якщо партнер вийшов або зв'язок обірвався, гра продовжується соло з повідомленням.

### Транспорт

Клас `Realtime` — це прямий WebSocket до Supabase Realtime за протоколом Phoenix
(`wss://<проєкт>.supabase.co/realtime/v1/websocket?apikey=…&vsn=1.0.0`): `phx_join`, `broadcast`,
heartbeat кожні 25 с. Жодної бібліотеки з CDN — гра лишається одним файлом і онлайн працює навіть
при відкритті з локального файлу.

Присутність гравців зроблена самою грою: кожні 2 секунди летить маленький `hi`, і якщо від партнера
нічого не чути понад 7 секунд, він вважається відключеним. Це навмисно не покладається на
server-side presence.

Уся ігрова логіка ходить через `NET.send` / `NET.onMsg`, тому транспорт можна замінити, не чіпаючи
гру. Позиції розсилаються ~14 разів на секунду.

**Безпека.** У сторінку потрапляє лише `anon public` ключ — він і створений для того, щоб бути в
клієнті. **Ніколи не встромляй сюди `service_role`.** Для гри варто завести окремий Supabase-проєкт,
де немає інших даних.

## Однакові рівні: seed

Генерація рівня детермінована: `withSeed(seed, () => buildLevel(world, diff))`. Той самий seed завжди
дає той самий рівень — ті самі кубики, монстри, колодязі й бос. Це основа і для мультиплеєра, і для
домашніх завдань. `SESSION.pin = true` означає «цей seed зафіксовано» (домашка або онлайн-кімната);
у вільній грі seed щоразу новий.

## Мої курси (редактор контенту)

Розділ **My Courses & Words**: курс → секції (юніти) → уроки. Кожен урок має свої слова й граматику
і його можна запустити окремо, разом із секцією або як весь курс. Власний контент зливається з
вбудованими банками (`syncCourses()`), тому проходить через ті самі формати завдань — картинки,
аудіювання, правопис, зайве слово тощо — без окремого коду.

Формат слів (один рядок — одне слово):

```
kitchen | 🍳 | the room where you cook
stairs  |    | steps that take you up to the next floor
roof
```

Формат граматики (один рядок — одне питання):

```
He ___ football. | play; plays; playing | 2 | We add -s after he, she and it.
? Make it negative: "He is happy." | he is not happy; he isn't happy | Add not after be.
! She don't know. | She; don't; know | 2 | Third person needs doesn't.
# The train leaves at six | Present Simple for timetables.
```

`?` — учень вводить відповідь (кілька написань через `;`), `!` — учень тикає на помилку,
`#` — учень складає речення. Без префікса — звичайний вибір, число вказує правильний варіант.

Курси експортуються та імпортуються як JSON (`{"courses":[…]}`), тож ними можна ділитися з колегами.
Кнопка **Load example course** додає готовий приклад із правильним форматом.

## Домашнє завдання одним кодом

Teacher Mode → **Create an assignment code**. Код містить теми, складність, світ, seed **і самі уроки**,
якщо вони власні. Учень вставляє код у Teacher Mode → Open an assignment і грає точно той самий рівень
із тими самими словами — навіть якщо твого курсу в нього немає.

## Персонаж і аватар

Розділ **Character & Avatar**: ім'я (видиме партнеру в онлайні), аватарка-емодзі та вибір героя.
Шість героїв — це один і той самий намальований спрайт із перефарбованою бронею: перефарбовуються
лише сині пікселі (`tintSheet()`), тож волосся, шкіра й шарф лишаються як намальовані. Сьомий —
старий векторний герой. Коли з'являться справжні малюнки, достатньо дати герою поле `sheet`
з посиланням на його аркуш.

## Стабільність

Рівень не може «залипнути»: питання й квести захищені кількома запобіжниками.

* `askActive` — друге питання ніколи не перезаписує відкрите (раніше це залишило б гру чекати на відповідь,
  якої вже немає в DOM).
* Watchdog у `loopStep()` — якщо `LV.busy` тримається понад ~2.5 с, а жодного діалогу на екрані немає,
  рівень автоматично розблоковується (`unstick()`).
* Усі асинхронні обробники (`hitBlock`, `fight`, `bossAttackTry`, `interact`, `runeStone`, `runQuest`)
  загорнуті в `try/catch` — помилка всередині не залишає гру заблокованою.
* Глобальні `error` і `unhandledrejection` теж викликають `unstick()`.
* `clearKeys()` скидає стан клавіш і екранних кнопок при відкритті/закритті діалогу, при `blur` і при
  перемиканні вкладки — затиснута клавіша більше не «залипає».
* Перехід у фонову вкладку ставить рівень на паузу і зупиняє музику; планувальник музики не робить
  «залпу» нот після повернення.
* `speak()` не накладає озвучки одна на одну (`cancel()` + невелика затримка) — це типова причина зависань
  Web Speech у Chrome при швидких повторах.

## Ліцензія на графіку

Спрайт героя взято з аркуша, який ти надав. Перед публічним релізом варто перевірити ліцензію цього
набору — гра розповсюджує зображення разом із кодом (воно вбудоване в `index.html`).

## Наступні кроки після MVP

1. Більше контенту: решта Grammar-тем зі списку, 2000+ слів, англійські визначення для medium-рівня, власні картинки замість емодзі.
2. Спрайти та анімації замість векторних форм; окрема музика для кожного світу.
3. Режими Boss Rush, Endless Run, Classroom Mode, Custom Level.
