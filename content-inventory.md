## Grammar

### Verb to be  `to-be`

**Easy**

1. *[вибір варіанта]* I ___ a student.  
   варіанти: am / is / are  
   ✔ **am** — Use "am" with I.
2. *[вибір варіанта]* She ___ my sister.  
   варіанти: am / is / are  
   ✔ **is** — Use "is" with he, she, it.
3. *[вибір варіанта]* They ___ at home.  
   варіанти: is / are / am  
   ✔ **are** — Use "are" with we, you, they.

**Medium**

1. *[вибір варіанта]* ___ your parents at work?  
   варіанти: Is / Are / Do  
   ✔ **Are** — In questions the verb "be" goes first.
2. *[ввести відповідь]* Make it negative: "He is happy."  
   ✔ **he is not happy** — Add "not" after the verb "be".
3. *[вибір варіанта]* There ___ a lot of people in the hall.  
   варіанти: is / are / be  
   ✔ **are** — "People" is plural, so we use "are".

**Hard**

1. *[знайти помилку]* Find the mistake: "The news are very good today."  
   варіанти: The / news / are / good  
   ✔ **are** — "News" is uncountable and singular: news is.
2. *[вибір варіанта]* ___ there any milk left in the fridge?  
   варіанти: Are / Is / Have  
   ✔ **Is** — Milk is uncountable, so "Is there…?"
3. *[скласти речення]* Put the words in the correct order:  
   ✔ **These trousers are too tight** — "Trousers" is always plural.

### Present Simple  `present-simple`

**Easy**

1. *[вибір варіанта]* He ___ football every day.  
   варіанти: play / plays / playing  
   ✔ **plays** — We add -s after he, she and it.
2. *[вибір варіанта]* ___ you like pizza?  
   варіанти: Do / Does / Are  
   ✔ **Do** — Use "do" with I, you, we, they.
3. *[вибір варіанта]* My cat ___ milk.  
   варіанти: drink / drinks / drinking  
   ✔ **drinks** — Third person singular takes -s.

**Medium**

1. *[вибір варіанта]* She ___ her homework in the evening.  
   варіанти: do / does / dos  
   ✔ **does** — do becomes "does" for he/she/it.
2. *[ввести відповідь]* Write the correct form: "Tom ___ (study) English."  
   ✔ **studies** — Consonant + y changes to -ies.
3. *[вибір варіанта]* We ___ go to school on Sunday.  
   варіанти: don't / doesn't / not  
   ✔ **don't** — Use "don't" with we.

**Hard**

1. *[знайти помилку]* Find the mistake: "She don't know the answer."  
   варіанти: She / don't / know / answer  
   ✔ **don't** — Third person needs "doesn't".
2. *[вибір варіанта]* Choose the correct option: "I ___ this song. It's wonderful."  
   варіанти: am liking / like / likes  
   ✔ **like** — "Like" is a stative verb — no continuous form.
3. *[скласти речення]* Put the words in the correct order:  
   ✔ **The train leaves at six tomorrow** — We use Present Simple for timetables.

### Present Continuous  `present-continuous`

**Easy**

1. *[вибір варіанта]* Look! The baby ___ .  
   варіанти: sleep / is sleeping / sleeps  
   ✔ **is sleeping** — Action happening now: be + -ing.
2. *[вибір варіанта]* We ___ TV at the moment.  
   варіанти: watch / are watching / watches  
   ✔ **are watching** — "At the moment" signals Present Continuous.
3. *[ввести відповідь]* Write the correct form: "They ___ (run) in the park now."  
   ✔ **are running** — Double the final consonant: running.

**Medium**

1. *[вибір варіанта]* ___ she working today?  
   варіанти: Is / Does / Do  
   ✔ **Is** — Continuous questions start with is/are.
2. *[вибір варіанта]* I ___ the guitar every Monday, but today I ___ the piano.  
   варіанти: play / am playing / am playing / play / play / play  
   ✔ **play / am playing** — Routine = Simple, now = Continuous.
3. *[ввести відповідь]* Make it negative: "He is working." →  
   ✔ **he is not working** — Put "not" after is.

**Hard**

1. *[знайти помилку]* Find the mistake: "I am knowing this rule very well."  
   варіанти: I / am knowing / this / rule  
   ✔ **am knowing** — "Know" is stative: I know.
2. *[вибір варіанта]* "You ___ always ___ your things!" (you are annoyed)  
   варіанти: are / losing / do / lose / have / lost  
   ✔ **are / losing** — Continuous + always expresses irritation.
3. *[скласти речення]* Put the words in the correct order:  
   ✔ **We are meeting our teacher on Friday** — Continuous for fixed arrangements.

### Past Simple  `past-simple`

**Easy**

1. *[вибір варіанта]* Yesterday I ___ to the park.  
   варіанти: go / went / goes  
   ✔ **went** — go is irregular: went.
2. *[вибір варіанта]* She ___ a letter last night.  
   варіанти: write / wrote / writes  
   ✔ **wrote** — write → wrote.
3. *[ввести відповідь]* Write the correct form: "We ___ (play) football yesterday."  
   ✔ **played** — Regular verbs add -ed.

**Medium**

1. *[вибір варіанта]* ___ you see the film last week?  
   варіанти: Did / Do / Was  
   ✔ **Did** — Past questions use did + base form.
2. *[вибір варіанта]* He ___ come to the party.  
   варіанти: didn't / doesn't / wasn't  
   ✔ **didn't** — Negative: didn't + base form.
3. *[ввести відповідь]* Write the correct form: "They ___ (stop) the car."  
   ✔ **stopped** — Double the consonant: stopped.

**Hard**

1. *[знайти помилку]* Find the mistake: "Did you went to school yesterday?"  
   варіанти: Did / you / went / yesterday  
   ✔ **went** — After "did" use the base form: go.
2. *[вибір варіанта]* While I ___ home, I met an old friend.  
   варіанти: walked / was walking / walk  
   ✔ **was walking** — Longer background action: Past Continuous.
3. *[скласти речення]* Put the words in the correct order:  
   ✔ **He did not tell us the truth** — did not + base form.

### Future Forms  `future`

**Easy**

1. *[вибір варіанта]* I think it ___ rain tomorrow.  
   варіанти: will / going / is  
   ✔ **will** — Predictions and opinions use "will".
2. *[вибір варіанта]* Look at those clouds! It ___ rain.  
   варіанти: will / is going to / goes  
   ✔ **is going to** — Evidence now → be going to.
3. *[вибір варіанта]* We ___ visit grandma next Sunday. (a plan you have made)  
   варіанти: are going to / will / go  
   ✔ **are going to** — Plans and intentions: be going to.

**Medium**

1. *[ввести відповідь]* Make it negative: "She will help us." →  
   ✔ **she will not help us** — will not = won't.
2. *[вибір варіанта]* The train ___ at 7:15.  
   варіанти: will leave / leaves / is leaving  
   ✔ **leaves** — Timetables use Present Simple.
3. *[вибір варіанта]* Don't worry, I ___ carry your bag.  
   варіанти: will / am going to / carry  
   ✔ **will** — Spontaneous decisions use "will".

**Hard**

1. *[вибір варіанта]* By 2030 scientists ___ a cure for this illness.  
   варіанти: will find / will have found / are finding  
   ✔ **will have found** — Completed before a future point: Future Perfect.
2. *[вибір варіанта]* This time tomorrow we ___ over the ocean.  
   варіанти: will fly / will be flying / fly  
   ✔ **will be flying** — In progress at a future moment: Future Continuous.
3. *[знайти помилку]* Find the mistake: "I will call you when I will arrive."  
   варіанти: will call / when / will arrive / you  
   ✔ **will arrive** — After "when" use Present Simple.

### Articles  `articles`

**Easy**

1. *[вибір варіанта]* I have ___ apple.  
   варіанти: a / an / the  
   ✔ **an** — Use "an" before a vowel sound.
2. *[вибір варіанта]* This is ___ big dog.  
   варіанти: a / an / —  
   ✔ **a** — Use "a" before a consonant sound.
3. *[вибір варіанта]* Look at ___ moon!  
   варіанти: a / an / the  
   ✔ **the** — Unique things take "the".

**Medium**

1. *[вибір варіанта]* She plays ___ piano every evening.  
   варіанти: a / the / —  
   ✔ **the** — Musical instruments take "the".
2. *[вибір варіанта]* I go to ___ school by bus.  
   варіанти: a / the / —  
   ✔ **—** — "go to school" has no article.
3. *[вибір варіанта]* I bought a hat. ___ hat was very cheap.  
   варіанти: A / The / —  
   ✔ **The** — Second mention takes "the".

**Hard**

1. *[вибір варіанта]* ___ Alps are higher than ___ Snowdon.  
   варіанти: The / — / — / the / The / the  
   ✔ **The / —** — Mountain ranges take "the"; single peaks do not.
2. *[вибір варіанта]* He was elected ___ president of the club.  
   варіанти: a / the / —  
   ✔ **—** — No article after "elected/appointed" + position.
3. *[знайти помилку]* Find the mistake: "The life is full of the surprises."  
   варіанти: The life / is / full / the surprises  
   ✔ **The life** — General ideas take no article.

### Prepositions of Place  `prep-place`

**Easy**

1. *[вибір варіанта]* The cat is ___ the table. (on the surface)  
   варіанти: in / on / under  
   ✔ **on** — "On" = on a surface.
2. *[вибір варіанта]* The ball is ___ the box. (inside)  
   варіанти: in / on / at  
   ✔ **in** — "In" = inside.
3. *[вибір варіанта]* The dog sleeps ___ the bed. (below it)  
   варіанти: on / under / over  
   ✔ **under** — "Under" = below something.

**Medium**

1. *[вибір варіанта]* I'll meet you ___ the bus stop.  
   варіанти: in / at / on  
   ✔ **at** — "At" = a specific point.
2. *[вибір варіанта]* There is a bridge ___ the river.  
   варіанти: over / in / between  
   ✔ **over** — "Over" = above and across.
3. *[вибір варіанта]* The shop is ___ the bank and the café.  
   варіанти: among / between / next  
   ✔ **between** — "Between" = two things.

**Hard**

1. *[вибір варіанта]* He lives ___ the third floor ___ a small flat.  
   варіанти: in / on / on / in / at / on  
   ✔ **on / in** — on the floor, in a flat.
2. *[вибір варіанта]* The village lies ___ the foot of the mountain.  
   варіанти: at / in / on  
   ✔ **at** — Fixed phrase: at the foot of.
3. *[знайти помилку]* Find the mistake: "She was standing in front the mirror."  
   варіанти: standing / in front / the / mirror  
   ✔ **in front** — The phrase is "in front of".

### Comparatives  `comparatives`

**Easy**

1. *[вибір варіанта]* A car is ___ than a bike.  
   варіанти: fast / faster / fastest  
   ✔ **faster** — Short adjectives add -er.
2. *[вибір варіанта]* This is the ___ book in the library.  
   варіанти: big / bigger / biggest  
   ✔ **biggest** — Superlative: the + -est.
3. *[ввести відповідь]* Write the correct form: "Winter is ___ (cold) than autumn."  
   ✔ **colder** — cold → colder.

**Medium**

1. *[вибір варіанта]* This test is ___ than the last one.  
   варіанти: more difficult / difficulter / most difficult  
   ✔ **more difficult** — Long adjectives use "more".
2. *[вибір варіанта]* Your idea is ___ mine.  
   варіанти: as good as / so good as / gooder than  
   ✔ **as good as** — Use "as … as" for equality.
3. *[ввести відповідь]* Write the correct form: "She is the ___ (good) student in class."  
   ✔ **best** — good → better → the best.

**Hard**

1. *[вибір варіанта]* The more you practise, ___ you speak.  
   варіанти: the better / better / the best  
   ✔ **the better** — the + comparative, the + comparative.
2. *[вибір варіанта]* It was ___ far more expensive than we expected.  
   варіанти: by / — / the  
   ✔ **—** — "far/much" intensify comparatives.
3. *[скласти речення]* Put the words in the correct order:  
   ✔ **This is by far the most interesting museum** — "by far" strengthens superlatives.

### Modal Verbs  `modals`

**Easy**

1. *[вибір варіанта]* I ___ swim very well.  
   варіанти: can / can to / cans  
   ✔ **can** — After "can" use the bare infinitive.
2. *[вибір варіанта]* You ___ eat in the classroom. It is forbidden.  
   варіанти: mustn't / don't must / can  
   ✔ **mustn't** — "mustn't" = prohibition.
3. *[вибір варіанта]* ___ I open the window?  
   варіанти: May / Do / Am  
   ✔ **May** — "May" asks for permission.

**Medium**

1. *[вибір варіанта]* You ___ take an umbrella — it is not raining.  
   варіанти: mustn't / don't have to / can't  
   ✔ **don't have to** — "don't have to" = no necessity.
2. *[вибір варіанта]* She ___ be at home; her car is outside.  
   варіанти: must / can't / needn't  
   ✔ **must** — "must" = strong deduction.
3. *[вибір варіанта]* You ___ see a doctor. (advice)  
   варіанти: should / must not / could have  
   ✔ **should** — "should" gives advice.

**Hard**

1. *[вибір варіанта]* He ___ the message; he never checks his phone.  
   варіанти: can't have seen / must have seen / should see  
   ✔ **can't have seen** — can't have + past participle = certainty it did not happen.
2. *[вибір варіанта]* You ___ told me earlier! I would have helped.  
   варіанти: should have / must have / can have  
   ✔ **should have** — should have + V3 = criticism about the past.
3. *[знайти помилку]* Find the mistake: "He must to finish the report today."  
   варіанти: He / must to / finish / today  
   ✔ **must to** — No "to" after must.

### Present Perfect  `present-perfect`

**Easy**

1. *[вибір варіанта]* I ___ my homework. Here it is!  
   варіанти: do / have done / did  
   ✔ **have done** — Result now: have + past participle.
2. *[вибір варіанта]* She ___ never ___ to London.  
   варіанти: has / been / have / been / is / been  
   ✔ **has / been** — Third person: has been.
3. *[вибір варіанта]* ___ you ever seen a whale?  
   варіанти: Have / Did / Are  
   ✔ **Have** — "ever" goes with Present Perfect.

**Medium**

1. *[вибір варіанта]* We ___ here since 2019.  
   варіанти: live / have lived / lived  
   ✔ **have lived** — "since" needs Present Perfect.
2. *[вибір варіанта]* I ___ my keys yesterday.  
   варіанти: have lost / lost / has lost  
   ✔ **lost** — A finished time word needs Past Simple.
3. *[ввести відповідь]* Write the correct form: "He ___ (just / finish) the test."  
   ✔ **has just finished** — "just" goes between have and the participle.

**Hard**

1. *[вибір варіанта]* How long ___ you ___ English?  
   варіанти: have / been learning / are / learning / did / learn  
   ✔ **have / been learning** — "How long" + ongoing action: Perfect Continuous.
2. *[вибір варіанта]* This is the first time I ___ sushi.  
   варіанти: try / have tried / tried  
   ✔ **have tried** — After "the first time" use Present Perfect.
3. *[знайти помилку]* Find the mistake: "I have seen him three days ago."  
   варіанти: I / have seen / him / three days ago  
   ✔ **have seen** — "ago" needs Past Simple.

### Conditionals  `conditionals`

**Easy**

1. *[вибір варіанта]* If you heat ice, it ___ .  
   варіанти: melts / will melt / melted  
   ✔ **melts** — Zero conditional: present + present.
2. *[вибір варіанта]* If it rains, we ___ at home.  
   варіанти: stay / will stay / stayed  
   ✔ **will stay** — First conditional: if + present, will + base.
3. *[вибір варіанта]* If I ___ time, I will help you.  
   варіанти: have / will have / had  
   ✔ **have** — No "will" after "if".

**Medium**

1. *[вибір варіанта]* If I ___ rich, I would travel the world.  
   варіанти: am / were / will be  
   ✔ **were** — Second conditional: if + past, would + base.
2. *[вибір варіанта]* She would call you if she ___ your number.  
   варіанти: knows / knew / had known  
   ✔ **knew** — Imaginary situation: past after "if".
3. *[ввести відповідь]* Complete the sentence: "If I were you, I ___ (not go) there."  
   ✔ **wouldn't go** — would not + base form.

**Hard**

1. *[вибір варіанта]* If we ___ earlier, we wouldn't have missed the train.  
   варіанти: left / had left / would leave  
   ✔ **had left** — Third conditional: if + past perfect, would have + V3.
2. *[вибір варіанта]* If he had studied medicine, he ___ a doctor now.  
   варіанти: would be / would have been / will be  
   ✔ **would be** — Mixed conditional: past condition, present result.
3. *[скласти речення]* Put the words in the correct order:  
   ✔ **You can borrow it as long as you return it** — "as long as" = provided that.

### Passive Voice  `passive`

**Easy**

1. *[вибір варіанта]* The room ___ every day.  
   варіанти: cleans / is cleaned / cleaning  
   ✔ **is cleaned** — Passive: be + past participle.
2. *[вибір варіанта]* These cars ___ in Germany.  
   варіанти: are made / make / is made  
   ✔ **are made** — Plural subject: are made.
3. *[вибір варіанта]* The letter ___ yesterday.  
   варіанти: sent / was sent / is sent  
   ✔ **was sent** — Past passive: was/were + V3.

**Medium**

1. *[вибір варіанта]* The bridge ___ next year.  
   варіанти: will build / will be built / builds  
   ✔ **will be built** — Future passive: will be + V3.
2. *[скласти речення]* Rewrite in the passive: "Shakespeare wrote Hamlet."  
   ✔ **Hamlet was written by Shakespeare** — The object becomes the subject; the agent takes "by".
3. *[вибір варіанта]* The house ___ painted at the moment.  
   варіанти: is being / is / was  
   ✔ **is being** — Continuous passive: is being + V3.

**Hard**

1. *[вибір варіанта]* The problem ___ before we arrived.  
   варіанти: had been solved / was solving / has solved  
   ✔ **had been solved** — Past perfect passive: had been + V3.
2. *[вибір варіанта]* He ___ to be the best player in the league.  
   варіанти: is said / says / has said  
   ✔ **is said** — Impersonal passive: He is said to be…
3. *[знайти помилку]* Find the mistake: "The window was broke by the storm."  
   варіанти: window / was / broke / storm  
   ✔ **broke** — Use the past participle: broken.
